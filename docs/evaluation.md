# Evaluation protocol
Run only when ready: `uv run docintel evaluate` or `uv run --extra vision docintel evaluate --backend local_vlm --output outputs/vision-evaluation.json`.
Nine original synthetic fixtures are annotated in evals/manifest.json. Classification uses per-class one-vs-rest precision/recall/F1. Field PRF counts a correct non-null annotation as TP, incorrect non-null predictions as FP, absent/wrong required gold values as FN. Exact match compares serialized values literally; normalized match collapses whitespace/case and uses 0.02 tolerance for monetary fields. Ordered row accuracy divides correct rows by max(predicted, gold) row count. Evidence scoring requires correct page, an existing quote and matching value. Review accuracy compares explicit expected booleans. Reconciliation rate counts passing subtotal+tax checks over all documents, including non-billing attachments. Undefined precision/recall is null; F1 zero when undefined.
No results have been generated. Synthetic samples and templates favor the rules baseline and do not measure real generalization. VLM evaluation intentionally includes mandatory human review, so its review accuracy will not equal baseline acceptance accuracy. Expand with independently authored, licensed documents and adjudicated labels before making performance claims. Model failures produce review results and count as extraction failures; no silent fallback. Sample scan review expectations assume readable OCR; missing Tesseract can correctly cause extra review flags.
